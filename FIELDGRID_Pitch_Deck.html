01 / THE PROBLEM

From visual evidence to structured information

Field photographs are useful evidence, but by themselves they are often unstructured. FIELDGRID addresses the gap between visual evidence and structured condition data.

THE GAP

VISUAL EVIDENCE → STRUCTURED DATA

DOCUMENTATION NEEDS

  • Identify visible conditions
  • Mark findings directly on imagery
  • Classify observations consistently
  • Capture reference measurements
  • Preserve visual evidence with structured data
FIELDGRID · AXAYACATL02
02 / THE SOLUTION

One photograph. One structured condition record.

FIELDGRID is a browser-based, hardware-agnostic workflow for turning an ordinary photograph into a condition record.

  1. LOAD — Load an ordinary photograph locally.
  2. MARK — Add points or bounding boxes.
  3. CLASSIFY — Assign standardized categories.
  4. MEASURE — Add a reference scale.
  5. EXPORT — Create annotated PNG and machine-readable JSON.
